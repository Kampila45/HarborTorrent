# HarborTorrent Changelog

## v1.0.1
- **Automatic Updates**: HarborTorrent now automatically checks for updates in the background! You'll get a friendly notification when a new version is ready, keeping you on the latest and greatest version effortlessly.
- **Lightning Fast Downloads**: We've supercharged download speeds and fixed Magnet Link support by enabling decentralized peer finding (DHT & PEX).
- **Search Fixes**: Fixed a bug where certain built-in search engines were hiding or overriding each other.
- **Linux Stability**: Resolved a critical startup crash on Fedora and other Linux distributions.

## v1.0.0
- **Initial Release!** Welcome to HarborTorrent.
- **Robust Engine**: Powered by a highly efficient core engine for fast and reliable downloads.
- **Live Updates**: Real-time progress bars and speed graphs that update instantly.
- **Flexible Adding**: Drop in a `.torrent` file or paste a Magnet Link to get started.
- **Anchor Mode**: Need to preserve your internet speed while gaming or streaming? Toggle Anchor Mode to instantly throttle global bandwidth usage.
